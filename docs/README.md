# Documentation Index

This folder contains operational and technical documentation for the Finder back-office project.

## Available Documents

- `DEPLOY.md` - Production deployment guide for VPS with Docker and nginx.
- `deploy-implementation.md` - Original implementation context and deployment assumptions.
- `ARCHITECTURE-README.md` - Application architecture overview and detailed source tree.
